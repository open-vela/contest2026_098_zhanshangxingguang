# VelaFit —— 端侧多模态 AI 运动健康助手（openvela × BK7258）

## ① 项目名称与一句话定位

**VelaFit —— 端侧多模态 AI 运动健康助手（openvela × BK7258）**。

在完全离线、数据不出设备的前提下，用板端算力完成"摄像头隔空测心率 + 运动识别 + 心率异常预警 + 离线语音交互"的健康闭环，解决可穿戴 / AIoT 设备"离线即失智、健康隐私被迫上云"的痛点。同时把 openvela 移植到全新芯片 BK7258，为生态补齐一块板级支持。

## ② 目标开发板及选板理由

目标板：**BK7258 devkit**（博通集成 BK7258，AIoT WiFi + BLE SoC；本作品完成其 openvela 适配）。

选板理由：

1. **高集成、演示完整**：单板即带双圆形 LCD、摄像头、音频（喇叭 + MIC）、跑马灯 LED、WiFi + BLE、电池，覆盖"感知—端侧推理—显示—语音—声光提醒"全链路，无需外挂即可完整 demo。
2. **算力扛得住端侧 AI**：多核 + 音视频 / AI 加速，足以实时跑 rPPG 视觉模型与轻量 KWS / 分类模型（TFLite Micro / CMSIS-NN 级）。
3. **形态贴近真实手表**：双圆屏还原度高，UI 演示直观。
4. **生态价值**：openvela 尚无 BK7258 现成移植，本作品完成从内核启动、驱动（LCD / Camera / Audio / GPIO-LED）到应用栈的适配，是可回馈社区的板级贡献。

## ③ 核心功能（逐条含所需硬件能力）

1. **摄像头非接触心率检测（rPPG）【明星功能】** —— 手指 / 面部贴近摄像头，端侧视觉模型从皮肤微色变提取脉搏波估算心率。硬件：板载摄像头 + AI 加速；全端侧，无需 PPG 接触式传感器。
2. **运动识别与实时指标（步数 / 配速 / 心率区间）** —— 硬件：外接 IMU 加速度计模块（I2C / SPI）；端侧规则 + 轻量分类。
3. **端侧异常心率 / 健康预警（静息 / 运动心率突变）** —— 端侧推理；预警联动**跑马灯 LED + 喇叭**做声光提示，无需联网。
4. **离线语音交互（唤醒 + 命令词"开始运动 / 查询心率"）** —— 硬件：MIC + 喇叭；端侧 KWS。
5. **双圆屏可视化** —— 一屏运动仪表盘、一屏实时心率曲线 / 预警，分屏联动。硬件：双圆形 LCD + 背光，LVGL。
6. **数据同步与可选云端增强** —— 联网时同步记录、下载星历加速定位。硬件：WiFi。

> 具体外设以 BK7258 devkit 官方规格为准；IMU / PPG 等缺失传感器用扩展模块替代，rPPG 路径不依赖接触式心率传感器。

## ④ 各功能技术方案（端侧 / 云端、框架 / SDK）

- **openvela 适配（底座工作项）**：完成 BK7258 的 openvela（NuttX）启动与板级驱动移植——LCD（双屏）、Camera（DVP）、Audio（喇叭 / MIC）、GPIO 跑马灯、WiFi / BLE，打通 uORB / cpc / property-eventbus 与 LVGL（lvx）。
- **rPPG 心率**：端侧，摄像头帧流 → ROI 提取 → 轻量 CNN / 信号处理反演脉搏波 → 心率；TFLite Micro / CMSIS-NN 推理。
- **运动识别**：端侧，IMU 数据经 uORB 订阅 → 规则 + 轻量分类模型。
- **异常预警**：端侧阈值 + 轻量时序模型，结果驱动 LED / 喇叭声光提示。
- **语音交互**：端侧唤醒 + 离线命令词（openvela 语音 / ASR 组件或轻量 KWS）；复杂问答可选走云端 LLM（联网时）。
- **UI**：LVGL 双圆屏分屏渲染，复用 openvela lvx 组件。
- **通信 / 同步**：cpc + property / eventbus 做模块间 / 核间通信；WiFi 走标准网络栈，云端可选 HTTP / MQTT。
