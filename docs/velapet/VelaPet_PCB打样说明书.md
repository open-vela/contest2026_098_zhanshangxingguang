> 用途：用大赛发的**嘉立创打样券**做一版 VelaPet 专用板。本文给方案选择、下单参数、
> 交付文件、以及**跟工作人员必须沟通/确认的点**，可直接照着执行。
>
> 本文由两份早期草稿合并而成（2026-08-14），是唯一有效版本。
>
> ⚠️ **先读第〇节的方案选择再动手** —— 全自制 BK7258 主板难度高，且 **BK7258 不在嘉立创元件库**，
> 别盲目上。

## 〇、方案选择（先定这个）

### ⚠️ 为什么不建议重做 BK7258 主板

据官方《AN01-BK7258 硬件应用手册 V1.2》与嘉立创元件库现状：

| 风险点 | 说明 |
|---|---|
| **芯片不在嘉立创库** | BK7258（QFN88 9×9，**0.4mm pitch**）在嘉立创/LCSC 无货号 → SMT 无法自动贴片，必须**自供芯片寄件（consignment）**，或 BOM 标 **DNP 后自己手焊**（0.4mm QFN 手焊难度很大） |
| 射频匹配 | AN01 有专章讲射频匹配调试，需**实测调试**（矢网/频谱仪），做不好 Wi-Fi 直接不通 |
| 4 层阻抗控制 | Reference design 明确建议四层板，RF 与关键走线要严格照手册，重排稍有不慎射频/时钟就废 |
| 26M 晶体上电时序 | AN01 §2.1 专门讲上电时序对晶体的要求（**推荐 2016 封装**），选错/布局不当会不启动 |
| BUCK 电感与布局 | AN01 §4 有布局要点（**4.7uH，MPH201210S4R7MT**），做不好电源不稳 |
| 特殊器件也多需自供 | GC9D01 / GC2145 / MFRC522 / SC7A20H / HT687x 大多不在嘉立创库 |
| 周期 | 设计 + 打样 + 贴片 + 调试通常 **2–4 周且常需二次改版** |

**时间账**：作品提交截止 **9 月 20 日**，券有效期到 10 月 31 日。主板重做一旦翻车，直接吃掉移植时间。

### ✅ 推荐：VelaPet 载板 / 转接背板（2 层，低风险）

**不重做主板**，只做一块 **2 层载板**，把现有开发板的外设按萌宠形态**可靠地引出并固定**。

**它要解决的是我们真实存在的四个问题**（不是为了做板而做板）：

| 现存问题 | 载板如何解决 |
|---|---|
| **双麦间距只有 1~2cm，寻声做不了**（实测；需 ≥60mm） | 板上做**两个咪头固定位，中心间距 60–70mm**，走线规整、左右对称 |
| **M2 麦座接触不良**（交换测试确认是座子/焊点问题，不是麦坏） | **重新引出一对可靠的麦座**，绕开原板那个冷焊的座子 ⭐ 这是载板最大的实际价值 |
| 飞线多、拆装易断（尤其 SWD 与咪头细漆包线） | 统一用 1.25mm 座汇聚 + 应力释放孔，一根排线接主板 |
| 情绪灯效可控性差 | 加 2–4 颗 **WS2812B**（单线串行，省 IO），做情绪呼吸/流水灯 |

**电路内容（极简，无射频、无高速）**
- 2 × 咪头座（1.25mm，对称布置，**中心间距 65mm**）+ 双绞走线区
- 1 × 排线座（引到主板 M1/M2 麦克风座）
- 2–4 × WS2812B + 每颗 100nF 去耦 + 首端 300Ω 串阻
- 1 × 3pin 座（WS2812：VCC/DIN/GND）
- 可选：2 × 轻触按键 + 10K 上拉；NFC 线圈引出 2pin 座
- 丝印：`VelaPet CARRIER V1.0`、`L-MIC`/`R-MIC`、极性标记、座子脚序

> **布线注意**：麦克风是**模拟高阻信号**，务必与 WS2812 数据线、电源线**分区并加地隔离**；
> 两条麦克风线**等长 + 双绞/差分对走线**，否则会引入噪声、破坏 TDOA 相位一致性。

**板型**：长条形（"耳朵横梁"造型）约 **75 × 15 mm**，或按外壳内腔调整；4 × Φ2.2mm 安装孔。

### 结论
**优先做载板**：难度低、便宜（20 元券覆盖）、**24–48 小时出板**、零射频风险，
而且直接解决麦间距与 M2 接触不良两个真问题，同样吃「硬件工程能力」评分，**且不阻塞移植主线**。

主板裁版仅在**移植主线（M1–M3）已完成且有硬件工程师支持**时作为冲刺加分，参数见第六节。

## 二、需交付给嘉立创的文件

**PCB 打样必需**
- **Gerber**（RS-274X，含各层 + 阻焊 + 丝印）+ **钻孔文件**（Excellon），打包成一个 zip
  - LCEDA：`导出 → Gerber`
- **板框**（在 Gerber 的机械层/GKO 层里定义外形）

**SMT 贴片另需**
- **BOM 表**（`.csv`：位号 Designator / 值 Value / 封装 Footprint / **LCSC 商品编号 C 号**）
- **坐标文件 CPL / Pick-and-Place**（`.csv`：位号 / X / Y / 旋转 / 层 Top-Bottom）
  - LCEDA：`制造 → BOM`、`制造 → 坐标文件`
- 装配说明（可选）：标注极性元件方向（WS2812 缺角、咪头极性）

| 参数 | **载板（推荐）** | 主板裁版（高风险） |
|---|---|---|
| 层数 | **2 层** | **4 层**（射频需要） |
| 尺寸 | 约 75 × 15 mm（按外壳内腔） | 参考现板框 **53.5 × 46.1 mm** |

| 板厚 | 1.6mm | 1.6mm（或按堆叠） |

| 铜厚 | 1oz | 外层 1oz / 内层 0.5oz |

## 四、SMT 贴片参数

| 项 | **载板（推荐）** | 主板裁版 |
|---|---|---|
| 贴片面 | 单面（Top） | 单/双面（按布局） |
| 元件数 | 少（座子/排针/少量阻容/WS2812） | 多（全主板） |
| **主控 BK7258** | 载板无主控，**无此问题** ✅ | **不在嘉立创库 → 自供寄件 或 DNP 自焊** |
| 元件来源 | 全是常规件，嘉立创基础/扩展库有 | 阻容库里有；GC9D01/GC2145/MFRC522/SC7A20H/HT687x **多需自供** |
| 钢网 | 视需要 | 若自己手焊/返修，**建议加购钢网** |

> **关键**：凡嘉立创库里没有的器件，要么**自供寄件贴片**，要么 BOM 里标 **DNP** 自己后焊。
> 下单前用 LCEDA 的「BOM 匹配」或直接把 BOM 发客服，请其逐个标注"可贴 / 需自供 / 建议 DNP"。
>
> **建议**：咪头、1.25mm 座这类插件（THT）**自己手焊**，只让 SMT 贴 WS2812 和阻容，省钱且更灵活。

## 五、与工作人员沟通

### 5.1 下单话术（PCB，可直接复制）

> 您好，我是 2026 openvela AI 硬件开发者大赛的参赛选手，客编号 **【填客编号】**。
> 我要打一块 **2 层板**，尺寸约 **75×15mm**，数量 **5 片**，板厚 1.6mm，
> 黑色阻焊白色字符，喷锡工艺，常规线宽线距（6/6mil），**不需要阻抗控制**。
> 使用大赛发放的 **PCB 打样券（20 元/张）** 抵扣，请帮我确认券能否正常使用。

### 5.2 下单话术（SMT）

> 这块板还需要 **单面 SMT 贴片**（顶层），贴 **5 片**。
> 元件是 WS2812B 和常规阻容，我会提供 **BOM（含立创商城 C 料号）+ 坐标文件**，元件请代购。
> 插件类（1.25mm 座、咪头）我自己手焊，**不需要贴**。
> 使用大赛发放的 **SMT 贴片券（100 元）** 抵扣。

### 5.3 必问清单

1. **券的适用范围**：PCB / SMT / 3D 各自额度、能否叠加、是否需在指定入口下单
2. **器件可贴性**：把 BOM 发过去，请对方标出"可贴 / 需自供 / 建议 DNP"
3. **DFM 检查**：发 Gerber/BOM/坐标后，请先做**可制造性检查**再开工，避免打回重做
4. **交期**：打样 + SMT 的**总交期**（赶 9/20 截止，需倒排）
5. **发货**：收货地址、运费是否含在券内
6. **（仅主板裁版必问）** "BK7258（QFN88 9×9，**0.4mm pitch**）贵司库里没有，我**自供芯片寄件**
   可以贴吗？这个间距贵司 SMT 能做吗？需要我提供钢网/回流曲线吗？"
7. **（仅主板裁版必问）** "板含 2.4G 射频，需 50Ω 阻抗控制，请给推荐堆叠（stackup）与对应线宽，
   我按此改 layout。"

## 六、主板裁版方案参数（仅供有余力时使用）

### 6.1 设计来源
- 起点：`vendor/openvela/docs/HDK-BK7258_QFN88_9X9/HDK-BK7258_QFN88_9X9_V3.5/1.Reference design/SCH-BK7258_QFN88_9X9_Reference_V3.5.json`（**立创 EDA 原生格式，可直接打开**）
- 版图参考：同目录 `2.EVB desgin/*/Layout/` 与 `3.Module desgin/Layout/`
- **必读**：`AN01-BK7258V1.2.pdf`，尤其 §1 供电稳压管、§2 26M 晶体上电时序、§3 电源滤波电容、
  §4 BUCK 电感选型与布局、§5–6 射频电感电容与匹配调试/版图建议

### 6.2 裁剪建议
**保留**：BK7258 + 电源（含 26M/32.768k 晶体）、RF 与天线、UART0+CH340 调试口、
USB 充电管理（ETA3422）、锂电接口与 ADC0 电量检测、双 SPI 屏接口、DVP 摄像头接口、
双麦 + HT687x 功放 + 喇叭座、SD NAND、按键、LED、MFRC522 NFC。
**可裁**：以太网 PHY、TF 卡（若用 SD NAND）、多余测试点与排针、LCD 50PIN FPC 子板接口（改板载直连）、
**震动马达（本项目已弃用，见下方备注）**。

### 6.3 沟通要点（务必主动说明）
> 这是一块 **4 层 Wi-Fi SoC 板**，主控 **BK7258 QFN88 9×9（0.4mm pitch）**，含 **2.4G 射频与天线**。
> 需要 **阻抗控制**（RF 单端 50Ω），请帮我做 **DFM 检查**，重点看：
> ① QFN88 焊盘扇出与钢网开窗；② RF 走线阻抗与参考层完整性；③ BUCK 电感区域散热与布局。
> 主控与部分外设需自供寄件，请确认可行性。
> 我参考的是原厂 Reference design V3.5 与硬件应用手册 AN01 V1.2。

## 附：与当前硬件状态的对齐（2026-08-14）

设计载板时请以这些**实测结论**为准（详见《VelaPet_硬件变更记录》）：

- **双麦已装**（2 颗同款 6027 ECM，200mm 双绞线 + 1.25mm 插头），但**实测麦头间距仅 1~2cm**，
  寻声需 ≥60mm → **这是载板要解决的首要问题**
- **M2 麦座接触不良**（交换测试确认是座子/焊点问题）→ 载板应重新引出可靠麦座
- **震动马达已物理割断正极线**（与 LCD 背光共用 LDO，调试时太吵；项目不使用震动）
  → **载板与外壳都不需要为马达留位**
- **屏电源总闸在 P52**；左眼 SPI = P2/3/4/5，右眼 = P22/23/24/7/6
- **P20/P21 = SWD**，任何上电流程必须跳过；SWD 引线极脆，载板宜提供**应力释放**固定点
