# 寻声 MIC2 求助 · 给官方的沟通文字（存档 2026-08-10）

> 用途：BK7258 开发板双麦寻声，MIC2（第二路模拟麦）信号间歇不稳，向官方/平台求助。
> 现状小结：MIC1 稳定可用；MIC2 间歇 RMS=0；交换麦后"0"仍留在 MIC2 通道 → 非麦本身；官方参考板默认只接 MIC1、MIC2 未接。

---

**主题：BK7258 开发板 双麦（MIC1+MIC2）模拟音频采集 —— MIC2 通道信号不稳定，求助配置/硬件**

你好！我们是 BK7258 赛道参赛队，基于 openvela/NuttX 做双眼 AI 陪伴机器人，其中一项功能是**双麦声源定位（左右寻声）**。在启用第二路麦克风时遇到 MIC2 通道不稳，想请教是平台默认配置、软件配置遗漏，还是硬件层面的原因。详情如下：

**一、硬件改动**
- **官方参考板默认只接了 MIC1 一颗麦，MIC2 未接**（第二个麦座未连通/未贴麦）——这也是我们怀疑问题根源的关键点。
- 为做双麦寻声，我们换成 **2 颗同型号麦**（6027 ECM 驻极体，-25±3dB，双绞线），分别接到板上 **MIC1(M1±) / MIC2(M2±)** 两个差分模拟麦座，并拉开约 21cm 以获得足够的到达时间差（TDOA）。

**二、软件/驱动**
- 平台 openvela/NuttX，参照 Armino SDK 的音频路径，在**寄存器级**做了双通道模拟音频 ADC 采集 bring-up：音频电源域（pwd_audp）、音频时钟（aud_cken）、APLL、模拟前端（MICBIAS/ADCBIAS/AUDBIAS）、**MIC1_EN 与 MIC2_EN（ana_reg19/27 的 bit28）**、差分模式、ADC 使能、FIFO 轮询读取 L/R 双通道 16-bit PCM。

**三、现象**
- **MIC1（左）稳定**：能采到正常 PCM，RMS 随声音变化，寻声左侧判定正确。
- **MIC2（右）间歇性 RMS=0**：去直流后完全为 0（像电气开路；正常麦即使安静也有 ~30+ 底噪），时有时无，导致互相关退化、方向乱跳。

**四、已做排查**
- **交换两颗麦到对方麦座**后，"0" **仍固定出现在 MIC2/右通道**（没有跟着麦走）→ 判断不是麦本身坏，而是 MIC2 座/走线/右通道这条路的问题，或平台默认未使能/未连通 MIC2。

**五、想请教**
1. **既然官方参考板默认只接 MIC1、MIC2 未接**，平台/固件是否**默认只使能或只路由 MIC1**？要启用 **MIC2（第二路模拟麦）**，是否还需要额外的软件配置（Kconfig、板级配置、ADC 通道/声道使能、模拟寄存器、pinmux 等）我们没配到？
2. 开发板上的 **MIC2(M2) 座在硬件上是否本就未完全连通**（既然出厂未贴麦），需要哪些**板级改动**（补焊/跳线/贴件/上拉 MICBIAS 等）才能让 MIC2 正常工作？有没有官方的双麦硬件说明或原理图对应位置？
3. BK7258 模拟音频 ADC 做 **双通道（MIC1+MIC2）同步采集**，官方有无推荐的配置流程或注意事项（尤其两路增益/相位一致性、MICBIAS 供给）？

**六、对我们的影响**
- 双麦寻声（TDOA/GCC-PHAT）**必须两路都稳定同步**。目前 MIC1 单路可用，但 MIC2 不稳导致左右定位无法可靠工作。若能稳定 MIC2，"听声转头/转眼"功能即可完成。

如需要，我们可提供**寄存器配置清单、两路采集日志（RMS/样点）、现象录屏**。非常感谢！
