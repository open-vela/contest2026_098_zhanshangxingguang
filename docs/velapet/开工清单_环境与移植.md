## 3. 装 AI 编程环境（技能集 + Claude Code + MiMo）

### 3.1 一键装机（推荐，换电脑就用这个）

本目录下的 `install_claude_skills_new.sh` 把三件事一次做完：拉技能集到项目根 `.claude/`、装 Claude Code CLI、写好 MiMo 接入配置并做连通性自检。

- [ ] 一条命令搞定（`tp-xxx` 换成自己的 Token Plan key，最后的路径换成 openvela 项目根目录）：
      ```bash
      cd /path/to/velapet          # 脚本所在目录
      MIMO_API_KEY=tp-你的key ./install_claude_skills_new.sh -y ~/openvela/vela_ap
      ```
      key 走环境变量而不是 `-k`，避免明文进 shell history。
- [ ] 跑完**新开一个终端**（让 PATH 和配置生效），然后：
      ```bash
      cd ~/openvela/vela_ap && claude
      ```
      首次启动选 **Trust This Folder**；进去后 `/status` 看 Base URL 和模型，`/context` 看上下文窗口。

常用参数：

| 参数 | 用途 |
|---|---|
| `-y` | 非交互，全部取默认值（需配合 key 使用） |
| `-k KEY` / `MIMO_API_KEY` | Token Plan **专属 API key**（`tp-` 开头，控制台「专属 API key」栏） |
| `--1m` | 开 1M 长上下文（模型 ID 加 `[1m]` 后缀） |
| `-m NAME` | 换模型，默认 `mimo-v2.5-pro` |
| `--skip-skills` / `--skip-cli` / `--skip-config` | 分步补装，某一块已装好就跳过 |
| `--no-test` | 跳过连通性自检（自检会消耗极少量额度） |
| `-h` | 完整帮助 |

只补 MiMo 配置、不动技能集和 CLI：

```bash
./install_claude_skills_new.sh --skip-skills --skip-cli -k tp-你的key
```

### 3.2 MiMo 接入要点（手工配置时看这里）

脚本会写 `~/.claude/settings.json`（权限 600）。手工配的话，**四个模型变量必须都写**——Claude Code 内部按 sonnet/opus/haiku 三档分别发请求，只设 `ANTHROPIC_MODEL` 会让后台任务去请求 `claude-haiku-*`，MiMo 不认这个模型名：

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://token-plan-cn.xiaomimimo.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "tp-你的key",
    "ANTHROPIC_MODEL": "mimo-v2.5-pro",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "mimo-v2.5-pro",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "mimo-v2.5-pro",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "mimo-v2.5-pro"
  }
}
```

还要有 `~/.claude.json` 里的 `{"hasCompletedOnboarding": true}` 才能跳过登录引导。

- **只用专属 API key**：控制台「专属 API key」栏那个 `tp-` 开头的，配套 Base URL 固定是 `https://token-plan-cn.xiaomimimo.com/anthropic`，走套餐额度。脚本已锁死这一种，传 `sk-`（按量付费，走账户余额）会被直接拒掉。
- **环境变量优先级高于 settings.json**：配置不生效先查 `env | grep ANTHROPIC`，旧的 `~/.claude_code_env` 会静默覆盖新配置（脚本会检测并禁用它）。
- **前置**：Node.js 18+。装不上或权限报错用 nvm，别 `sudo npm`。
- **安全**：`settings.json` 含密钥，权限 600，别提交到 git、别截图外发。若 `~/.claude` 本身是 git 仓库，脚本会自动加 `.git/info/exclude`。
- 官方文档：https://mimo.mi.com/docs/zh-CN/tokenplan/integration/claudecode

- [x] **PSRAM（M2/M3 前置）** ✅ **实测 16MB，独立堆可用，614KB 摄像头帧可分配**。

      而 614KB 摄像头帧在 336K SRAM 里放不下）。

### 7.4 ⭐ 顺带发现的加分机会：自制 PCB / 外壳
- HDK 的原理图源文件是 **`.json` = 嘉立创 EDA（LCEDA）原始格式**，可直接在 LCEDA 打开修改。
- 而大赛正好发 **嘉立创打样券包（PCB + SMT + 3D 打印，价值 400 元）**。
- 评分表里「技术难度」含 **硬件工程能力**、「产品创新性」含 **硬件形态设计创新**。
→ **结论**：完全有条件基于 Reference design 裁一版 VelaPet 专用小板，或至少用 3D 打印做一个"双眼萌宠"外壳，把裸板变成有形态的产品。**投入不大，加分明确，且能显著提升路演观感**。
→ 建议排期：**移植主线跑通后**再做（别抢占 M1–M3 的时间）；外壳（3D 打印）性价比最高，优先做外壳、PCB 视余力。

### 7.5 麦克风位置 —— 已查明（结论：外接式，间距自定）
查位号图 + 原理图得到：
- 麦克风**不是板载 SMD**，而是经 **`HC-1.25-2PLT` 2pin 座外接**：**CN7 = MIC1**、**CN9 = MIC2**、**CN8 = 喇叭**；三者**均在底层**、沿同一侧边缘竖排。
- 座子间距：**CN7↔CN9 ≈ 9.4mm**、CN7↔CN8 ≈ 8.3mm（位号图 1:1，板框跨度实测 **53.5 × 46.1 mm**，与实物照片吻合）。
- 推荐麦克风型号：`AM_065200-GML020`。

**⚠️ 实物核对结果：两个麦克风座（丝印 M1 / M2）只装了 1 颗麦，另一座空置。** 已装那颗用细漆包线引到**面板两眼正中**（居中拾音，对唤醒最优）。喇叭是独立座，实装一颗**较大的喇叭**在外壳侧面。

**影响：**
- ✅ 语音唤醒 / 命令词（核心功能）**单麦即可，不受影响**。
- ⚠️ 双麦寻声需**自行采购并接上第二颗麦**（`AM_065200-GML020` 或兼容 2pin 模拟 MEMS 麦），并把两颗拉开 ≥60mm、采样率取 48kHz。
- 现有那颗已能从底层边缘走线到面板正中，说明**线长足够**支撑 60mm 布置。
- 详细取舍见《VelaPet_作品描述》「A 方案的取舍建议」——**基线走摄像头人脸跟踪**，寻声列为进阶。

**采购规格（若要做双麦寻声）：**
- **类型：驻极体咪头（ECM）** ✅ —— 原理图前端为 ECM 偏置网络（`MICBIAS` + R70 1K / R71 10K，差分 `MIC+/MIC-` 加 10pF/1uF 耦合），**不要买数字 MEMS/PDM 麦**。
- **尺寸**：原装推荐 `AM_065200-GML020`（约 Φ6.0×2.0mm）；市售 **6027（Φ6.0×2.7mm）直径一致可用**，高度差由自制外壳吸收。
- **⚠️ 接头必须是 1.25mm 间距**（板上座子为 `HC-1.25-2PLT`）。市售常见 2.0mm 间距**插不进**——下单前问卖家要 **XH1.25 / SH1.25 / MX1.25** 端子；或买不带插头版自行压端子；或直接焊到焊盘。
- **建议买 2–4 颗同型号并把原装那颗一起换掉** —— TDOA/GCC-PHAT 需要两麦**相位与灵敏度一致**，混用不同型号会降低测向精度。单价约 ¥1.6，成本可忽略。
- **选"带咪套"版本** —— 便于外壳固定，兼隔离机械振动噪声。
