口播为**逐字中文稿**,直接照读。拍法二选一:

## 🎬 推荐拍法:单机位「一镜到底」(最省事)

用**手机支架**固定手机,让**显示器(串口文字)+ 板子(双眼/摄像头/喇叭)同框**(见下图机位)——一个画面同时拍到"敲命令"和"板子当场反应"。这样能**跳过一大半流程**:

- ❌ 不用电脑录屏软件(GNOME/OBS 都不用)
- ❌ 不用把"屏录 + 板子实拍"两路在后期对齐/合成画中画
- ✅ **命令→反应在同一镜头里**,因果直观、更有说服力
- ✅ 一条音轨即可(手机麦同时收你的口播 + 喇叭应答"你好,我在")
- ✅ 后期只剩:**裁剪 + 给 `camera hr` 采样等待加速 + 打字幕 + 压到 ≤5min**(用电脑 kdenlive 或手机剪映/CapCut 都行)

**单机位 5 个要点**
1. **串口字看得清**:终端**字号调大 + 铺满屏**;显示器亮度适中(别泛光);关键行(`HR=60 good`、`MATCH`/`WAKE`)后期**打字幕**兜底。
2. **锁焦锁曝光**:开拍前点屏幕文字对焦,**锁定 AF/AE**,免得手伸去盖摄像头时画面来回对焦。
3. **防摩尔纹/反光**:手机尽量与屏幕**平行**、避开正对反光;有波纹就前后挪一点距离/角度。
4. **构图**:屏在上、板子在下,两者都入框;测心率时手指盖摄像头也在此框内完成。
5. **声音**:安静环境、口播清楚;先试录 5 秒回放,确认喇叭"你好,我在"能听清。

> 按 6 幕顺序一段段对着说、敲命令,基本一次拍完(某幕 NG 就单独重拍那一幕再拼)。
> 下面「录制操作」一节的电脑录屏方案作为**备选**——若嫌拍屏文字不够清,再改用电脑录串口 + 手机拍板子分拍。

## 一、开拍前 5 分钟自检清单

**环境 / 设备**
- [ ] 安静房间(命令词要现场说话);**光线稳定充足**(测心率靠环境光,别让光线忽明忽暗)。
- [ ] 板子固定放稳;串口连好:`fuser -k /dev/ttyUSB0; picocom -b 115200 /dev/ttyUSB0`。
- [ ] **终端字号调大**(方便视频看清);窗口拉宽,避免自动换行打乱输出。
- [ ] 固件是最新 `dev-ai` 编译烧录(含 `camera hr` / `kws` / `lcdtest`)。
- [ ] 手机/录屏软件就位;本稿口播词另开一屏或打印。
- [ ] **wifi/热点全程关着**(用来佐证"离线")。

**逐条复测(录之前先跑一遍确认稳)**
- [ ] `camera init` → `camera buf` → `camera hr`:手指轻盖摄像头、**保持静止**,末行出 `... good` 且 bpm 合理(≈55–90)。若出 `fair`/乱跳:调光、手指盖严一点、别压太紧,重试 2–3 次找到稳定手感。
- [ ] **预先登记(录制时直接 run,省时间)**,含**大赛指定唤醒词**:
      `kws clear`
      → `kws enroll nihaoopenvela`(说"你好openvela",**念快一点**,避免超过 1 秒被截)×2
      → `kws enroll chaxinlv`(说"查心率")×2
      → `kws enroll yundong`(说"开始运动")×2
      → `kws list`(应显示 6 条)。
      验证:说"你好openvela"→ `MATCH nihaoopenvela`;说命令词/无关话分别命中/拒识。
      > 唤醒词较长、1 秒窗口可能截尾,但登记与识别截同一段,匹配不受影响(念法保持一致即可)。
- [ ] `kws run` 说"开始运动"→ `MATCH yundong`;说一句无关话 → `REJECTED`。各试 2 次确认稳。
- [ ] `lcdtest oeye`、`lcdtest blink`:双屏眼神/眨眼正常。
- [ ] **情感整合**用 `camera velapet`(已确认真驱动眼睛 + LED):初始困倦眼 → **拿起→睁眼 + 绿灯** → **摇动→开心 + 红绿双灯** → 低电时**红灯闪("饿了")**。拿起/摇动由加速度计驱动、不依赖摄像头,可靠。
      > 唯一注意:有人脸时 TRACK 态眼睛可能轻微抖动——拍摄时**让板子别正对人脸,只演拿起/摇动**即可。若仍想更稳,退回 `lcdtest oeye`(眼神)+ `lcdtest accel g`(手势串口打印)分开拍。
- [ ] `lcdtest bat`:读出电量数值。低电红灯闪烁**需电量真的低**——若现场造不出,**口播带过即可,不强拍**。
- [ ] `lcdtest led <pin> <0|1>`:确认你板子的 LED 引脚号(红灯常见 P40),点亮/熄灭各一次。

> 只要"测心率出 good、命令词说对能中说错能拒、眼神能亮"这三样稳,就可以开拍。其余(低电红灯/LED)拍到算加分,拍不到不卡。

## 录制操作(GNOME 自带录屏 + 手机分工)

**分工原则**
- 🖥️ **电脑录屏**(串口文字):`help`/`free`、`camera hr`、`kws` 输出、GitHub PR 页面 → 用 GNOME 自带录屏,文字清晰。
- 📱 **手机拍**(板子实物 + 声音):双屏眼神、手指盖摄像头、拿起/摇动、**喇叭说话("你好,我在""没听清")** → **电脑录屏不录声音**,所以语音应答一定靠手机收音!

**GNOME 录屏怎么用(零安装)**
- 开始/停止:**Ctrl + Alt + Shift + R**(顶栏出现红点=正在录;再按一次停)。
- 存到 `~/Videos/Screencasts/*.webm`。
- **每段单独录**(录前按开始、敲完/说完按停)→ 得到独立小段,好剪。
- 录之前把**终端字号调大、窗口铺满屏**;它**只录画面不录声**,口播/喇叭声后期用手机音轨或配音补。

**每幕录法对照**
| 幕 | 🖥️ 电脑录屏 | 📱 手机拍 |
|---|---|---|
| 0 开场 | — | 板子全貌 |
| 1 适配 | `help`/`free` 串口 | `lcdtest oeye` 双屏 |
| 2 测心率 | `camera hr` 串口 | 手指盖摄像头(同步) |
| 3 语音 | `kws` 串口 | 你说话 + **喇叭应答(收音关键)** |
| 4 拟人 | — | velapet 眼神/拿起/摇动/灯 |
| 5 收尾 | GitHub PR / `logs/` 页面 | — |

**顺序建议**:先把电脑录屏的几段一次录完(幕1/2/3/5),再用手机补板子实拍(幕0/1/2/3/4),最后用 kdenlive 对齐拼剪、加字幕、导出 ≤5 分钟。
