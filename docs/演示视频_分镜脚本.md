# VelaPet 演示视频分镜脚本(≤5 min)

> 目标:突出"官方新板首次适配 + 全离线 + 真实可演示"。全程实机、串口/屏幕同框,不放假数据。

**0:00–0:30 开场(定位)**
- 画面:板子全貌(双圆屏亮着眼神动画)+ 一句话字幕:"VelaPet:跑在 BK7258 上的 openvela 端侧 AI 情感陪伴机器人,断网也不变傻。"
- 口播:点出这是大赛官方**待适配新板**,我们完成了 openvela 首次移植。

**0:30–1:15 底座:适配成果(证明硬)**
- 画面:串口 `help` 列出 builtin(camera/kws/lcdtest/mic…)、`uname`/`free`;双屏点亮 `lcdtest` 眼神表情。
- 口播:从启动引导 + UART 到双 QSPI 屏 / 摄像头 / 音频 / 加速度计 / 电量 ADC / PSRAM 的板级驱动,已提交并 PR 合入专属仓。

**1:15–2:30 亮点一:摄像头指尖测心率(rPPG)**
- 画面:`camera init` → `camera buf` → `camera hr`,**手指轻盖镜头保持静止**,串口打印 `HR = xx bpm`;可对比手环读数。
- 口播:这块板**没有 PPG 传感器**,心率是用摄像头 rPPG **算出来**的——难点与创新点都在这(隔空测量准确率有限,故用指尖)。

**2:30–3:45 亮点二:离线命令词识别(自研 MFCC+DTW)**
- 画面:`kws enroll` 登记"查心率""开始运动";`kws run` 说对 → MATCH,说无关 → REJECTED,串口显示距离;**拔掉 WiFi/热点**再演示一次,强调离线可用。
- 口播:纯 C、零第三方库、Apache-2.0;对比"必须联网、加载慢"的云端方案,我们**断网零延迟**。命中命令联动测心率。

**3:45–4:30 亮点三:拟人交互 + 情感闭环**
- 画面:`lcdtest oeye`/`blink` 双屏眼神动画;`lcdtest accel g` **拿起→唤醒、摇动→开心**;`lcdtest bat` 读电量,拔电演示**低电红灯闪烁**;`lcdtest led` 情绪灯。(如现场稳定可用 `camera velapet` 一条命令整合演示。)
- 口播:双圆屏当"会看人的眼睛",拿起就醒、摇动会开心、饿了(低电)会提醒——体感 + 声光把情绪外化,做出"陪伴感"。

**4:30–5:00 收尾(合规 + 生态)**
- 画面:GitHub 上已合入的 PR(#31 摄像头心率、#33 离线命令词)+ `logs/` AI 日志目录。
- 口播:全程 AI 辅助开发、日志可查、代码开源回馈 openvela 社区;并诚实说明已知限制(说话人相关、词表小)与后续升级路径(TFLM+DS-CNN、可选云端自由对话)。

> 补拍清单:板子全貌空镜、双屏眼神特写、`camera hr` 串口特写、`kws run` 断网演示、GitHub PR/logs 截图。
