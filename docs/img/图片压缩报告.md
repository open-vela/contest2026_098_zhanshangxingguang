# 作品展示照片 · 压缩报告

> 生成日期:2026-09-13
> 目的:大赛作品上传对**单张图片**有 5 MB 上限(实为 base64 编码后 ≤ 5 MB,原图需 < 约 3.75 MB),原图约 4 MB/张超限,故统一压缩。
> 原图已备份在 `docs/img/img_original/`,可随时恢复。

## 压缩参数

- 工具:ImageMagick 6.9.11(`mogrify`)
- 尺寸:最长边限制 `2000x2000>`(3072×4096 → 1500×2000)
- 质量:JPEG `quality 85`
- 文件名保持不变(README / 报告引用无需修改)

## 结论

- 6 张照片单张均从约 4 MB 降至约 1.7 MB,**base64 编码后约 2.4 MB/张,稳定低于 5 MB 上限**。
- 分辨率 1500×2000 仍清晰,足够多角度展示硬件实物。
- 另从「顶部.jpg」派生两张 README 配图:`velapet-overview.jpg`(板子全貌)、`velapet-eyes.jpg`(双圆屏眼神特写)。

## 复现命令

```bash
# 备份
mkdir -p img_original && cp *.jpg img_original/
# 批量压缩(原地,保持文件名)
for f in *.jpg; do mogrify -resize "2000x2000>" -quality 85 "$f"; done
```
